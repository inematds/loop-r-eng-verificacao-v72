Lesson 3 · 20 min

Frozen tests and a diff guard on the tests

If the agent can touch the judge, the judge is worthless. Freezing the tests means writing them first, keeping a snapshot of them out of the agent's reach, and failing any change. In this lesson you see that protecting only the tests/ folder is not enough: a conftest.py at the root skips everything and pytest exits with 0.

Start the lesson

In this lesson you will

  1. 1What "the judge" is: tests, conftest.py at any level, and the pytest config
  2. 2Manifest with a hash and a minimum test count, stored outside the repo
  3. 3The five failures: deleted, edited, new, too few, skipped
  4. 4The conftest hole in the headless loop, and the fix

Goal: freeze the judge (tests, conftest, config) with a hash and a minimum test count outside the repo, and fail on delete, skip, or edit.

02 · Rehearsal: three agents against the guard

Freeze before each agent and check afterward. GUARDA_DIR stays outside the project.

Terminal · apaga, conftest and bom
K=~/projetos/loop-r-eng-verificacao-v72/kit
export GUARDA_DIR=/tmp/ensaio-verif/guarda       # outside the repo
for modo in apaga conftest bom; do
  bash $K/ensaio.sh > /dev/null && cd /tmp/ensaio-verif/proj
  python3 $K/guarda-testes.py congelar .          # BEFORE the agent
  $K/agente-falso.sh $modo < /dev/null > /dev/null
  echo "## $modo"; python3 $K/guarda-testes.py conferir .; echo "saída: $?"
done

The 2 protected files are tests/test_slug.py and pytest.ini. In conftest mode, note "código 0": pytest thought everything was fine.

If you run congelar after the agent has already created conftest.py, it goes into the manifest as if it belonged to the project and the NOVO line disappears. Freeze on the base commit, before the first cycle. The guard would still reject it for PULADO, but you lose the clearest signal.

03 · The conftest hole in the headless loop

The loop-longrun.sh from course 2 reverts whatever the agent touches in PROTEGIDOS. With the example PROTEGIDOS ("tests/ pytest.ini"), a conftest.py at the root gets through and the final test "passes" with no test running. Rehearsal with a fake agent, at no cost.

Terminal · the hole (example PROTEGIDOS)
K=~/projetos/loop-r-eng-verificacao-v72/kit; L=~/projetos/execucao-longa/tools
bash $K/ensaio.sh > /dev/null && cd /tmp/ensaio-verif/proj
printf '#!/usr/bin/env bash\nexec %s/agente-falso.sh conftest\n' $K > /tmp/agente-conftest.sh
chmod +x /tmp/agente-conftest.sh
$L/novo-longrun.sh $PWD slug > /dev/null && D=$(ls -d $PWD/longrun/*)
echo "Implemente slug() em slug.py. Não mexa em tests/." > $D/prompt.md
cat > $D/loop.env <<'ENV'
TESTE_RAPIDO="python3 -m pytest -q"
TESTE_FINAL="python3 -m pytest -q"
PROTEGIDOS="tests/ pytest.ini"
PERMITIDOS="slug.py"
MAX_CICLOS=3
MIN_CICLO=2
MEM=1G
ESTAGNACAO=3
ENV
git add -A && git commit -qm "longrun: pasta"
CODEX_BIN=/tmp/agente-conftest.sh $L/loop-longrun.sh $D; echo "saída: $?"
Terminal · the fix (protected conftest + guard as the final test)
bash $K/ensaio.sh > /dev/null && cd /tmp/ensaio-verif/proj        # start over from scratch
export GUARDA_DIR=/tmp/ensaio-verif/guarda
python3 $K/guarda-testes.py congelar . > /dev/null
$L/novo-longrun.sh $PWD slug > /dev/null && D=$(ls -d $PWD/longrun/*)
echo "Implemente slug() em slug.py. Não mexa em tests/." > $D/prompt.md
cat > $D/loop.env <<ENV
TESTE_RAPIDO="python3 -m pytest -q"
TESTE_FINAL="GUARDA_DIR=$GUARDA_DIR python3 $K/guarda-testes.py conferir ."
PROTEGIDOS="tests/ pytest.ini *conftest.py"
PERMITIDOS="slug.py"
MAX_CICLOS=3
MIN_CICLO=2
MEM=1G
ESTAGNACAO=3
ENV
git add -A && git commit -qm "longrun: pasta"
CODEX_BIN=/tmp/agente-conftest.sh $L/loop-longrun.sh $D; echo "saída: $?"
ls conftest.py; grep -c "revertido pelo loop" $D/failures.md

error: pathspec 'conftest.py' did not match any file(s) known to git
2026-10-19 04:38:49 ciclo 1: checkpoint commitado
(… ciclos 2 e 3 iguais …)
2026-10-19 04:38:50 PARADO: 3 ciclos sem avanço mensurável — ver failures.md
saída: 2
ls: cannot access 'conftest.py': No such file or directory
3

"teste final passou ()": the empty parentheses are the passed count, which doesn't exist. In the fix, the error: pathspec line is harmless: git checkout doesn't know the new file, and the git clean right after removes it.

The loop-longrun.sh (execucao-longa kit, 10/18/2026) decides "done" by the exit code of TESTE_FINAL. Pytest exits 0 when every test is skipped, and the conftest.py at the root was not in PROTEGIDOS. Two locks fix it: protect *conftest.py (and whatever pytest config the project has) and use a TESTE_FINAL that requires the minimum passed with none skipped, like guarda-testes.py conferir.

06 · In three sentences

The judge is bigger than tests/conftest.py at any level and the pytest config also decide what runs.
Snapshot out of reachHash and minimum number of tests recorded before the agent, in a place where it can't write.
Code 0 is not enoughRequire the minimum of passed and no skipped; that's what closes the headless loop hole.
