Lesson 2 · 18 min

Command → output: check the criterion and the /goal evaluator

A criterion only counts if an outsider can check it without trusting the agent. In this lesson you run each criterion of goal.md as a command, see which one passes by shortcut, and learn where the proof has to show up: the /goal evaluator in Claude Code only reads the conversation.

Start the lesson

In this lesson you will

  1. 1The command → output format and the three kinds of expected output
  2. 2conferir-goal.py: OK or FALHOU per criterion, with exit code
  3. 3A criterion with no command and a criterion that passes by shortcut
  4. 4What the /goal evaluator sees, and what it doesn't

Goal: check each criterion of goal.md by command, see which level 2 one passes by shortcut, and put the proof in the conversation the /goal evaluator reads.

02 · The goal.md for the rehearsal

Six criteria. One has no command and one passes through a shortcut. Find both before you run it.

kit/goal-ensaio.md (criteria)
## Done criteria
**Function**
- [ ] `python3 -m pytest -q tests/` → `3 passed`
- [ ] `python3 -c "from slug import slug; print(slug('Ação & Reação!'))"` → `acao-reacao`

**Regression**
- [ ] `python3 -m pytest -q tests/ -rs` → `código 0`

**Limit**
- [ ] `git diff --stat HEAD -- tests/ pytest.ini` → `vazio`
- [ ] `git ls-files --others --exclude-standard -- '*conftest.py' tests/` → `vazio`
- [ ] the code stays clean and well documented
Terminal · before, shortcut and after
K=~/projetos/loop-r-eng-verificacao-v72/kit
bash $K/ensaio.sh > /dev/null && cd /tmp/ensaio-verif/proj
cp $K/goal-ensaio.md ../goal.md            # outside the project: the agent doesn't edit the criterion

python3 $K/conferir-goal.py ../goal.md; echo "saída: $?"     # A) before the work: it has to fail

$K/agente-falso.sh conftest < /dev/null                       # B) shortcut: skips the tests
python3 $K/conferir-goal.py ../goal.md; echo "saída: $?"

rm conftest.py && $K/agente-falso.sh bom < /dev/null           # C) the right work
sed -i '/limpo e bem documentado/d' ../goal.md                 #    and the criterion with no command goes away
python3 $K/conferir-goal.py ../goal.md; echo "saída: $?"

The command appears cut off at 60 characters in the output. In round B, código 0 gave OK with all three tests skipped: it's the level 2 criterion in goal.md.

If round A (before any work) already gives OK on a function criterion, the criterion doesn't measure the work. Every function criterion has to fail beforehand; limit criteria (nothing touched) can pass from the start.

03 · The /goal condition with proof

04 · Practice

Rehearsal, then your own goal.md.

E4 · Fails before, passes after

10 min

Run the three rounds of the rehearsal.

Done when: A ends with FALTAM 4 and saída: 4; B shows OK on the código 0 criterion and FALHOU on 3 passed; C ends with PRONTO and saída: 0.

E5 · Your goal.md checked

20 min

Take one of your own goal.md files (or write one from the course 2 template) and run conferir-goal.py on it before you start the work. Rewrite every criterion that came back as "sem comando" and every function criterion that already passes.

Done when: python3 $K/conferir-goal.py [seu goal.md] --pasta [seu projeto] → no sem comando line and at least one function FALHOU before the work (exit code greater than 0).

E6 · /goal with the proof pasted

20 min

Run a small task with /goal using the condition from the block above, pointing to your goal.md.

Done when: the agent's last reply contains the output of conferir-goal.py ending in PRONTO and /goal ends as met; when you run the same command yourself → PRONTO and exit code 0.

06 · In three sentences

CheckableA criterion with no command can't be checked; conferir-goal.py counts it as FALHOU.
Fails firstA function criterion that already passes before the work measures nothing; "exit code 0" alone passes with everything skipped.
Printed proofThe /goal evaluator only reads the conversation: the condition requires the pasted output ending in PRONTO.
